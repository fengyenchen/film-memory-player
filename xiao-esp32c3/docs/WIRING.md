# 接線指南

## 主要控制板：Seeed Studio XIAO ESP32-C3

本文件對應 Seeed Studio XIAO ESP32-C3。所有模組必須共地：TFT、EC11 與分壓電路的 GND 都接到開發板 `GND`；TFT 與 EC11 使用開發板的 `3V3` 供電。

> **Wi-Fi 天線注意事項：**
> - 確認 IPEX 天線接頭已確實垂直扣緊於 XIAO 的金色底座。
> - 天線貼片不要緊貼 LiPo、TFT 金屬背板或大量導線，也不要用金屬件包覆。
> - 天線盡量固定在遠離金屬與電源線的非金屬外殼內側。

## 電池與充電

```text
LiPo 正極 → XIAO 背面的 BAT+
LiPo 負極 → XIAO 背面的 BAT-

USB-C 充電器 → XIAO 原生 USB-C
```

USB-C 線直接插入開發板，另一端接一般 5V USB 充電器。只使用單節標稱 3.7V、充滿 4.2V 且具有保護板的 LiPo。

XIAO ESP32-C3 的官方充電電流約為 380mA，電池必須允許此充電電流。

> **電池安全：**
> - `BAT+`、`BAT-` 不可接反，也不可將 5V 接到 `BAT+`。
> - 不要同時使用外接 TP4056 與板載充電電路替同一顆電池充電。
> - 焊接前先拔除 USB-C，避免正負極或裸露接點短路。

## 電量偵測

使用兩顆 `100kΩ、1%` 電阻做 1:2 分壓。兩顆電阻的中間接點連到 D1 / A1（GPIO3）：

```text
BAT+ ── R1（100kΩ）──●── R2（100kΩ）── BAT-
                     │
               D1 / A1 / GPIO3
```

- `BAT+` 焊盤同時焊接電池紅線與 R1 的一端。
- `BAT-` 焊盤同時焊接電池黑線與 R2 的一端。
- R1、R2 剩下的兩端焊在一起，形成中間接點，再從這裡接到 D1 / A1（GPIO3）。
- `BAT-` 與開發板 GND 共地；如果 BAT- 焊盤太擠，R2 下端也可以改接開發板的 GND 腳。

單節 LiPo 充滿時最高約 4.2V，經分壓後 GPIO3 約讀到 2.1V。不可將 `BAT+` 直接接到 GPIO3。`SETTINGS` 顯示的是依電壓估算的約略百分比；USB 充電或負載變化時，讀值可能浮動或偏高。

## 螢幕模組（ST7735S 128×128 SPI TFT）

這塊螢幕使用 SPI 通訊，背光由 XIAO ESP32-C3 的 D0（GPIO2）直接控制。

| TFT 螢幕腳位標示 | 開發板腳位標示 | GPIO 編號 | 說明 |
| --- | --- | ---: | --- |
| **VCC / VDD** | `3V3` | - | 螢幕電源（3.3V） |
| **GND** | `GND` | - | 接地 |
| **SCL / SCK** | `D8` | 8 | SPI 時脈線（Clock） |
| **SDA / MOSI** | `D10` | 10 | SPI 資料線（Data） |
| **RES / RST** | `D7` | 20 | 螢幕重置（Reset） |
| **DC / RS** | `D2` | 4 | 資料／指令切換（Data/Command） |
| **CS / CE** | `D3` | 5 | 晶片選擇（Chip Select） |
| **BLK / BL** | `D0` | 2 | 螢幕背光直接控制 |

---

## 背光控制

```text
XIAO D0（GPIO2）→ TFT BLK / BL
```

> **背光注意事項：**
> D0（GPIO2）為 HIGH 時背光開啟，LOW 時背光關閉。進入休眠模式時，程式會將 GPIO2 鎖定為 LOW。

## 旋轉編碼器模組（EC11）

EC11 旋轉編碼器通常有 5 支腳：一側 3 支為旋轉訊號，另一側 2 支為按鈕訊號。

| EC11 腳位標示 | 開發板腳位標示 | GPIO 編號 | 說明 |
| --- | --- | ---: | --- |
| **GND / 共用端 C** | `GND` | - | 旋轉訊號的共用接地 |
| **+ / VCC** | `3V3` | - | 供電 |
| **CLK / A 相** | `D4` | 6 | 旋轉觸發訊號 A |
| **DT / B 相** | `D5` | 7 | 旋轉觸發訊號 B |
| **SW / 按壓開關** | `D6` | 21 | 按鍵輸入與休眠喚醒訊號 |

> **編碼器注意事項：**
> 1. D4、D5、D6 直接依照上表接線。
> 2. 如果向右轉卻變成上一張照片，將 CLK（D4）與 DT（D5）兩條線互換。
