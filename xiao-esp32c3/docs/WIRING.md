# 接線指南

## 主要控制板：Seeed Studio XIAO ESP32-C3

請將所有模組的接地（GND）都連接到 XIAO 板子上的 `GND` 腳位。供電部分，請使用板子上的 `3V3` 腳位。

> **💡 Wi-Fi 天線安裝：**
> * 確認 IPEX 天線接頭已確實垂直扣緊於 XIAO 上的金色底座（需有段落感）。
> * 天線貼片（或輻射端）不可緊貼 LiPo 電池表面或 TFT 螢幕的金屬背板，否則訊號會被嚴重遮蔽。
> * 請盡量將天線貼附於遠離金屬與電源線的非金屬外殼內側。

---

## 電池與充電

```text
LiPo 正極 → XIAO 背面 BAT+
LiPo 負極 → XIAO 背面 BAT-

USB-C 充電器 → XIAO 原生 USB-C
```

也就是把 USB-C 線直接接到 XIAO ESP32-C3 開發板本身的 USB-C；線的另一端接一般 5V USB 充電器。

XIAO 的官方充電電流約 380mA，電池必須允許此充電電流。

## 螢幕模組 (ST7735S 128x128 SPI TFT)

這塊螢幕使用 SPI 通訊，請確認 SCL 與 SDA 對應到 XIAO ESP32-C3 的硬體 SPI 腳位。背光由 XIAO GPIO2 直接控制。

| TFT 螢幕腳位標示 | XIAO 腳位標示 | GPIO 編號 | 說明 |
| --- | --- | --- | --- |
| **VCC / VDD** | `3V3` | - | 螢幕電源 (3.3V) |
| **GND** | `GND` | - | 接地 |
| **SCL / SCK** | `D8` | GPIO 8 | SPI 時脈線 (Clock) |
| **SDA / MOSI** | `D10` | GPIO 10 | SPI 資料線 (Data) |
| **RES / RST** | `D1` | GPIO 3 | 螢幕重置 (Reset) |
| **DC / RS** | `D2` | GPIO 4 | 資料/指令切換 (Data/Command) |
| **CS / CE** | `D3` | GPIO 5 | 晶片選擇 (Chip Select) |
| **BLK / BL** | `D0` | GPIO 2 | 螢幕背光直接控制 |

---

## 背光開關

```text
XIAO D0（GPIO2）→ TFT BLK / BL
```

> **💡 背光注意事項：**
> D0 為 HIGH 時背光開啟，LOW 時背光關閉。進入休眠模式時，程式會將 GPIO2 鎖定為 LOW。

---

## 旋轉編碼器模組 (EC11)

EC11 旋轉編碼器通常有 5 支腳，一側 3 支（旋轉訊號），另一側 2 支（按鈕訊號）。

| EC11 腳位標示 | XIAO 腳位標示 | GPIO 編號 | 說明 |
| --- | --- | --- | --- |
| **GND / 共用端 C** | `GND` | - | 旋轉訊號的共用接地 |
| **+ / VCC** | `3V3` | - | 供電 |
| **CLK / A 相** | `D4` | GPIO 6 | 旋轉觸發訊號 A |
| **DT / B 相** | `D5` | GPIO 7 | 旋轉觸發訊號 B |
| **SW / 按壓開關** | `D6` | GPIO 21 | 按下按鈕的開關訊號 |

> **💡 編碼器注意事項：**
> 1. `D4`、`D5`、`D6` 直接依照上表接線即可。
> 2. 如果發現「向右轉」卻變成「上一張照片」（方向顛倒），只要把實體接線的 **CLK (D4)** 和 **DT (D5)** 兩條線互換，方向就會正確了。
